- Keyboard: "Type what my keys say" in the keys menu sends the characters this keyboard and its input method make (another layout than the computer's, accents, Korean and Japanese), and shortcuts by the letters on its keys; off, keys go by where they are, for games and the computer's own layout. The choice is kept.
- At a size larger than the pane, the picture follows the pointer there when the person there or a program moves it (the view menu turns it off).
- A Windows computer whose remote access runs in the app without administrator rights: "Ask for administrator rights there" asks its person, and on their yes SSH Remote there opens again as administrator and the session goes on, with programs run as administrator and Windows' security prompts in reach.
- Switch sides: the person you help gets a window onto your computer, with its one-time password (which changes once used).

Install with one line (`irm https://sshremote.dev/install.ps1 | iex` in PowerShell, `curl -fsSL https://sshremote.dev/install.sh | sh` on macOS and Linux), or download the file for your system below. An installed copy updates itself with `sshremote update`. `SHA256SUMS` lists every file's SHA-256, as does the signed [list](https://sshremote.dev/download/latest.json) the program updates from.
