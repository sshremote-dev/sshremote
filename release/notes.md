- Teams: shared address books. An administrator makes lists of computers (by ID or SSH address, with tags and notes) and shares each with groups or people, to view or to edit; members see them in the app under the team's computers and open them as any address, and editors change them in the console. Every change is in the audit log; API tokens can read and manage them.
- Remote Desktop (RDP) from a computer's menu: Windows' own Remote Desktop there through a tunnel from this computer (SSH or by ID), opened in this computer's RDP client (Remote Desktop Connection, Windows App, FreeRDP or Remmina).
- With several monitors there, the picture can follow the window that comes in front as well as the pointer (Windows, X11, macOS, and GNOME with the helper); on a Mac with a Retina display, monitors side by side now lie as they do there.

Install with one line (`irm https://sshremote.dev/install.ps1 | iex` in PowerShell, `curl -fsSL https://sshremote.dev/install.sh | sh` on macOS and Linux), or download the file for your system below. An installed copy updates itself with `sshremote update`. `SHA256SUMS` lists every file's SHA-256, as does the signed [list](https://sshremote.dev/download/latest.json) the program updates from.
