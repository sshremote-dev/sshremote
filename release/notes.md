- Windows hosts with HDR on: the screen now looks as it does there. Windows composes an HDR desktop in half floats, with SDR white at the brightness set in its settings; it is asked for as it is and turned on the graphics card into what an SDR screen shows (SDR white read again each second, brighter colours scaled down whole so they keep their hue). Before, Windows clipped it and everything brighter than about 40% turned white.
- Shortcuts of your own for a screen's actions (Settings, Shortcuts): Ctrl+Alt+Del, full screen, the host's next or previous screen, screenshot, recording, chat, call, view only, sound, pause, repaint, the mouse for games and locking the computer. Off until turned on; each action starts on Ctrl+Alt+Shift and a letter, and any can be given other keys or none. They are taken where they are on the keyboard, before the host sees them.
- Only these IDs (remote access settings, or `remote-access ids`): a computer can let in viewers from some IDs alone, a star standing for any digits. The viewer proves it holds its device's key, and each ID comes in only from the device it first came from, so another computer cannot take its place; the settings list each ID's device to forget one that was replaced. Viewers before this version cannot come in where such a list is set.
- Ask the person there, even with a saved password: in a computer's menu in the list, or under the address. No password goes; reconnecting and the screens and files opened from it ask too.

Install with one line (`irm https://sshremote.dev/install.ps1 | iex` in PowerShell, `curl -fsSL https://sshremote.dev/install.sh | sh` on macOS and Linux), or download the file for your system below. An installed copy updates itself with `sshremote update`. `SHA256SUMS` lists every file's SHA-256, as does the signed [list](https://sshremote.dev/download/latest.json) the program updates from.
