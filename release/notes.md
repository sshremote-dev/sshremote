- Windows installer (MSI) for all users, also silent for many computers at once: `msiexec /i sshremote-windows-x86_64.msi /qn SERVICE=1 TEAM_URL=... TEAM_TOKEN=...` turns on remote access as a service and joins a team; upgrades need no restart, and `msiexec /x` takes it all away. The program now carries its version for Explorer.
- Remote access updates itself when nobody is connected (Windows service, Linux unit, Mac agent), checked against the signed list; "Update by itself" turns it off.
- Choose your own ID (6 to 12 digits) in remote access or with `sshremote remote-access id NUMBER`; if another computer has it, this one says so and keeps it until you choose another.
- A Linux computer with no desktop running (a server with no monitor) starts one of its own when a viewer asks for the screen: the lightest desktop installed there (Xfce, MATE, LXQt...), as its user, open only to that user, until it is signed out of. Files and terminals alone start nothing.
- A computer kept by its ID can be given addresses to reach it straight (its IP on a VPN or another network), tried before the relay; the list shows whether each computer by ID is online.
- Clipboard and files can go one way only, from or to this computer, for viewers by ID; the desktop picture can be taken away during sessions (Windows, GNOME, Cinnamon, MATE) and comes back after.
- The person at the computer sees how and from where someone connects; computers stay awake during sessions on both sides.
- Viewer: type a sign-in password at the remote lock screen (kept in this computer's password store if you like), trade the mouse buttons, turn the wheel the other way, go to the monitor the remote pointer moves onto, record every screen you open, and choose what happens when a file of the same name is there (keep both, replace, skip).
- Teams: API tokens for scripts (read only, devices, administration), failed sign-ins and every console change in the audit log with a retention setting, notes, owners and disabling for devices, and backup codes for two-step sign-in.

Install with one line (`irm https://sshremote.dev/install.ps1 | iex` in PowerShell, `curl -fsSL https://sshremote.dev/install.sh | sh` on macOS and Linux), or download the file for your system below. An installed copy updates itself with `sshremote update`. `SHA256SUMS` lists every file's SHA-256, as does the signed [list](https://sshremote.dev/download/latest.json) the program updates from.
