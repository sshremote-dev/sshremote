- On COSMIC, a viewer's first click on a host reaches it: the desktop's remote-desktop portal dropped the first pointer events of a session.
- A film playing on the host starts on the viewer 15 to 25 ms sooner, and the viewer uses up to about 60 MB less memory while it plays: films are decoded without libaom's row threads, which zeroed a quarter megabyte for every block of the picture at a film's start for no faster pictures after it.

Install with one line (`irm https://sshremote.dev/install.ps1 | iex` in PowerShell, `curl -fsSL https://sshremote.dev/install.sh | sh` on macOS and Linux), or download the file for your system below. An installed copy updates itself with `sshremote update`. `SHA256SUMS` lists every file's SHA-256, as does the signed [list](https://sshremote.dev/download/latest.json) the program updates from.
