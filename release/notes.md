- The Markdown view stays still as you scroll back past its top: a program that scrolls itself (an agent, a pager) adds what it brings above what you read, which no longer jumps back down. A view begun inside a code block of Markdown source no longer turns the rest of the document inside out, and a trackpad no longer springs the view back at the top.
- A host with two to four screens has a button for each in the screen toolbar, as RustDesk does; Ctrl+Alt+Shift with a screen's number switches to it from the keyboard (the host does not see those keys).

Install with one line (`irm https://sshremote.dev/install.ps1 | iex` in PowerShell, `curl -fsSL https://sshremote.dev/install.sh | sh` on macOS and Linux), or download the file for your system below. An installed copy updates itself with `sshremote update`. `SHA256SUMS` lists every file's SHA-256, as does the signed [list](https://sshremote.dev/download/latest.json) the program updates from.
