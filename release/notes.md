- Add a screen to the host for the session, as plugging in a monitor there would (a virtual one, none is needed): the screens menu offers sizes (this monitor's first), the new screen gets its own button and shows here as its other screens do, windows can be moved to it, and it goes again when you take it away or leave. For a computer without a monitor, or a screen of your own beside its person's. GNOME, Sway, Hyprland and X11 desktops, and Macs with a Metal GPU. MCP has it too (`add_screen`, `remove_screen`), so an AI agent can work on a screen of its own. Windows follows once tried on a real computer.
- A wlroots desktop's monitor that is unplugged leaves the list of its screens.

Install with one line (`irm https://sshremote.dev/install.ps1 | iex` in PowerShell, `curl -fsSL https://sshremote.dev/install.sh | sh` on macOS and Linux), or download the file for your system below. An installed copy updates itself with `sshremote update`. `SHA256SUMS` lists every file's SHA-256, as does the signed [list](https://sshremote.dev/download/latest.json) the program updates from.
