- Windows: the window opens on computers whose graphics driver crashes in Direct3D 12 (an Intel UHD 630 driver from 2020 did, at once, in 0.25.37 to 0.25.39: the program closed without a word). Such a crash before the window's first frames now starts it again on OpenGL, which that computer keeps from then on; `WGPU_BACKEND` still chooses by hand.
- Films are sharper than RustDesk's for fewer bytes (0.25.39): measured on one computer, each viewer's own pictures of the same film against the film itself, RustDesk 1.5.3 39.9-40.6 dB at 8.0 kbit a picture and SSH Remote 41.3 dB at 5.4 kbit; the whole bench took 1,124 KB against RustDesk's 2,190 KB, less in every part of it. A film's whole area always goes as a film.

Install with one line (`irm https://sshremote.dev/install.ps1 | iex` in PowerShell, `curl -fsSL https://sshremote.dev/install.sh | sh` on macOS and Linux), or download the file for your system below. An installed copy updates itself with `sshremote update`. `SHA256SUMS` lists every file's SHA-256, as does the signed [list](https://sshremote.dev/download/latest.json) the program updates from.
