- Full screen on all monitors for a host with more screens than this computer has monitors: each monitor shows one of its screens, as they lie, and the last one shows the screens left over side by side, so none of them opens in a window hidden behind the full-screen ones. With one monitor here, full screen shows the screen picked (its number button switches), or all of them side by side where the tab shows them so.

Install with one line (`irm https://sshremote.dev/install.ps1 | iex` in PowerShell, `curl -fsSL https://sshremote.dev/install.sh | sh` on macOS and Linux), or download the file for your system below. An installed copy updates itself with `sshremote update`. `SHA256SUMS` lists every file's SHA-256, as does the signed [list](https://sshremote.dev/download/latest.json) the program updates from.
