- 53 languages, the same as RustDesk's: the program speaks the system's language, or the one picked in Settings, Appearance, Language, with fonts for each script. Arabic, Persian, Urdu and Hebrew read right to left, also beside Latin words and over several lines. Messages from the other computer are shown in your language too, and the web viewer follows the browser's.
- Linux: remote access at the login screen and on a locked screen. Installing the service now also asks an administrator to set up a system service that runs a copy of the program as root with the same ID and password (`remote-access login-window on|off`). It reads the screen from the display hardware and types through virtual input devices on the system's keyboard layout, so it works with any login screen or lock screen (GDM, greetd, SDDM, LightDM, GNOME's or KDE's), with the keyboard and mouse only. Once the desktop is unlocked or someone signs in, the viewer moves on to the person's own remote access by itself, and back to the lock screen when it locks.

Install with one line (`irm https://sshremote.dev/install.ps1 | iex` in PowerShell, `curl -fsSL https://sshremote.dev/install.sh | sh` on macOS and Linux), or download the file for your system below. An installed copy updates itself with `sshremote update`. `SHA256SUMS` lists every file's SHA-256, as does the signed [list](https://sshremote.dev/download/latest.json) the program updates from.
