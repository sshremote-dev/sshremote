- Windows hosts add screens for a session too, as GNOME, Sway, Hyprland, X11 desktops and Macs do since 0.25.45: installing the helper service (remote access started with the computer) brings Amyuni Technologies' virtual display driver, usbmmidd, the one RustDesk uses; without it the screens menu shows the choice greyed, with what to do. Removing the service removes the device it made; a device or driver another program installed (RustDesk's) is used as it is and never removed.
- Adding a screen never installs anything on the spot.

Install with one line (`irm https://sshremote.dev/install.ps1 | iex` in PowerShell, `curl -fsSL https://sshremote.dev/install.sh | sh` on macOS and Linux), or download the file for your system below. An installed copy updates itself with `sshremote update`. `SHA256SUMS` lists every file's SHA-256, as does the signed [list](https://sshremote.dev/download/latest.json) the program updates from.
