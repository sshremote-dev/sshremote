- Remote printing: what is printed on the host to its new printer "SSH Remote" asks on the viewer to be printed on its default printer, kept as a PDF in Downloads, or let go. On Windows the printer comes with the helper service and uses Windows' own Microsoft Print To PDF driver; on Linux `sudo sshremote remote-access printer on` sets up a CUPS queue. Windows, macOS and Linux viewers print. A job printed while no viewer is connected waits for one.
- Hardware encoding: a film the processor falls behind on goes to the video hardware in H.264 (Media Foundation on Windows: Intel Quick Sync, NVIDIA NVENC, AMD AMF; VideoToolbox on macOS; GStreamer's VA-API, NVENC and Quick Sync encoders on Linux), and back to the processor if the hardware is no quicker. `SSHREMOTE_HW_ENCODE=0` never uses it, `1` always.
- On macOS, a viewer can keep the Mac's own keyboard and mouse out (Control+P at the Mac takes them back), and on Macs with Metal graphics hide its screen from whoever sits there while the viewer still sees it.

Install with one line (`irm https://sshremote.dev/install.ps1 | iex` in PowerShell, `curl -fsSL https://sshremote.dev/install.sh | sh` on macOS and Linux), or download the file for your system below. An installed copy updates itself with `sshremote update`. `SHA256SUMS` lists every file's SHA-256, as does the signed [list](https://sshremote.dev/download/latest.json) the program updates from.
