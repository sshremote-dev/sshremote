- A computer can be reachable at several relays at once (Also at in its remote access settings, or `sshremote remote-access also RELAY...`). Viewers that came in once learn where else it is, ask all of them at once, and go through whichever sees it when its own relay does not.
- A straight TCP path through the routers beside the UDP one: both sides connect to each other at once from the port the relay saw (relay 1.4 answers `seen`), for networks that let no UDP through; the first path that works carries the session, with nothing lost.
- Several people on one computer at the same time can see where the others point, with their names (the view menu: Show my pointer to others watching).

Install with one line (`irm https://sshremote.dev/install.ps1 | iex` in PowerShell, `curl -fsSL https://sshremote.dev/install.sh | sh` on macOS and Linux), or download the file for your system below. An installed copy updates itself with `sshremote update`. `SHA256SUMS` lists every file's SHA-256, as does the signed [list](https://sshremote.dev/download/latest.json) the program updates from.
