- Full screen uses all your monitors for a computer with several screens, as Remote Desktop's "use all my monitors": each of its screens goes full screen on the monitor here that lies where that screen lies on the computer (left on left, right on right, whichever is primary), so the pointer crosses from one to the next as it would there. Leaving full screen in one of them ends it in all, and Settings can turn it off. This computer's monitors are now read on Linux (X11 and Wayland) and macOS too, not only on Windows.
- With one monitor here, all of a computer's screens can show side by side in one tab (its screens menu, "All its screens here, side by side"), laid out as they lie on the computer and sized to fit; full screen keeps them together.
- Films and moving photographs on a remote screen go in AV1 where both ends have this version: at the same sharpness as RustDesk's AV1 they take about a third of its bytes a frame, and about a fifth fewer bytes than H.264 took before for a clearly sharper picture. Older viewers still get H.264.
- A window started with a computer to open (`sshremote --gui HOST`, `--local`) no longer stays on the start screen when a tiling window manager under X11 maximizes it while it grows.
- Windows opened for a computer's other screens show as SSH Remote's in the task bar under Wayland.

Install with one line (`irm https://sshremote.dev/install.ps1 | iex` in PowerShell, `curl -fsSL https://sshremote.dev/install.sh | sh` on macOS and Linux), or download the file for your system below. An installed copy updates itself with `sshremote update`. `SHA256SUMS` lists every file's SHA-256, as does the signed [list](https://sshremote.dev/download/latest.json) the program updates from.
