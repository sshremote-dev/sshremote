- A film starts sooner: its first picture is coded at libaom's fastest speed, so the wait as a film begins fell from about 100 ms to about 70 ms (RustDesk's longest wait in the same bench: 83-97 ms).
- The program carries the licenses of the open-source software built into it: `sshremote licenses` prints them, Settings opens them (Open-source licenses), and `THIRD-PARTY-NOTICES.txt` in the repository is kept current by CI.

Install with one line (`irm https://sshremote.dev/install.ps1 | iex` in PowerShell, `curl -fsSL https://sshremote.dev/install.sh | sh` on macOS and Linux), or download the file for your system below. An installed copy updates itself with `sshremote update`. `SHA256SUMS` lists every file's SHA-256, as does the signed [list](https://sshremote.dev/download/latest.json) the program updates from.
